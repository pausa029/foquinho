# Código-fonte da versão web do Foquinho

A página publicada em `web_site/web/index.html` é gerada a partir destes arquivos.

- `src/*.js`, `src/style.css`, `src/fonts.css`: o código.
- `build.py`: junta tudo em um HTML só (ajuste os caminhos no início do arquivo).
- `test/`: testes automáticos (Playwright).

Guardado em 11/11/2026, quando o projeto da escola mudou para o PACA.
